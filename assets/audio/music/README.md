# Background music assets

These four tracks were copied from the local **IRON DAWN 2.5D** project
(`红色警戒2.5D`) and are used as the adaptive score for this game:

- `ambient.mp3` — menu / idle
- `production.mp3` — unit production
- `combat.mp3` — combat
- `resolve.mp3` — victory / defeat resolution

Source project notes describe all image and music assets as generated from
original prompts with Suno, without Red Alert original units, insignia, UI or
melodies. Keep the source generation records with the 2.5D project when
publishing or redistributing this demo.

`music.json` contains the loop points, volume levels and transition settings
used by `src/audio/Audio.js`.
