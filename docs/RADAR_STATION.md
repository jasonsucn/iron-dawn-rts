# 雷达站重做记录

## 1. 问题

原雷达站的问题不是单纯的模型比例，而是动画对象引用错误：

- `makeModel()` 会把建筑根节点命名为建筑类型，雷达站根节点因此叫 `radar`；
- `resolveParts()` 通过 `getObjectByName('radar')` 查找雷达旋转头；
- `getObjectByName` 会包含根节点自身，因此返回了整栋建筑；
- `animateModel()` 对 `root.userData.radar.rotation.y` 赋值时，旋转的是整栋雷达站。

## 2. 修复

- 雷达旋转头改名为 `radar_head`；
- `resolveParts()` 改为查找 `radar_head`，超级武器的 `array` 保持兼容；
- 雷达房体保持静止，只有顶部天线组旋转。

验证结果：

- 根节点 `rotation.y = 0`
- `radar_head.rotation.y` 随时间变化
- `radarIsRoot = false`

## 3. 造型重做

雷达站不再使用方盒子主体，改为：

- 八角形混凝土/装甲塔身；
- 四个外扩斜向扶壁；
- 前置控制室、玻璃观察窗和遮檐；
- 偏置圆形发电/设备舱、管线和电缆；
- 侧置天线桅杆和顶部警示灯；
- 中部装甲环和阵营色环带。

顶部旋转组区分阵营：

- 盟军：倾斜抛物面雷达碟、四根支架、馈源灯；
- 苏军：大型平板缝隙阵列、金属栅格、前置警示灯。

## 4. 验证

- 全部 JS 语法检查通过；
- 核心回归测试 8/8 通过；
- 浏览器加载正常；
- 雷达站房体不旋转；
- 顶部 `radar_head` 独立旋转；
- 战术雷达状态正常切换为在线；
- 建筑图标和建造流程不受影响。

## 5. 当前限制

- 仍为程序化几何，不是 Blender GLB；
- 雷达碟/阵列材质为基础 PBR 纯色；
- 没有独立破损状态和 LOD；
- 苏军阵列的细节程度与盟军碟形雷达仍可继续区分。
